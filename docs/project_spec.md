
# Project 
Rapport is an application New Orleans citizens can use to report pot holes/street damage and catch basin cleaning. Reporting is based on New Orleans 311 call for service program. 


# Proposed pages
- Home page
- Service reporting flow, starting with selecting service type
- User service report dashboard
- User profile
- User reported service details

# Tech stack 
- Next framework 
- Bun  - Frontend framework 
- Fast api - backend
- AWS - lambda, api gateway, bedrock, agentcore, dynamodb, s3
- Jev system model
- GitHub actions 
- Terraform

# Data dependencies 
- Service schema
- User schema
